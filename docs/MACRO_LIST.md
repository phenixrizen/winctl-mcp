# macro.list

[Back to tool index](INDEX.md)

Agent name: `winctl-mcp`

Description: List session-promoted macros and memory-backed macro items.

## Inputs

- `kind`: optional macro kind filter.
- `tags`: optional required tags.
- `limit`: optional result limit.

## Notes

Session macros are stored in memory for the current server process. Memory-backed macro items come from the local memory database.
